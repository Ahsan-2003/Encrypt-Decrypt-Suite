# 🔐 Encryption Tool

A full-stack web application demonstrating 5 cryptographic techniques:
Caesar Cipher, AES, DES, Base64, and SHA-256 hashing.

Built as part of the **Information Security** course assignment.

## 📌 Features

- Encrypt & decrypt using 5 algorithms
- Server-side and client-side input validation
- Copy-to-clipboard for results
- SHA-256 one-way hashing
- Clean, responsive UI with real-time feedback

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML, CSS, Vanilla JavaScript |
| Backend | Node.js + Express |
| Encryption | CryptoJS |
| Dev Tool | Nodemon |

## 🚀 Setup & Run

```bash
# Clone the repository
git clone https://github.com/YOUR-USERNAME/encryption-app.git
cd encryption-app

# Install dependencies
npm install

# Start the server
npm run dev
